# Інструкція по створенню нових сторінок

## Використання єдиного header та footer

Всі файли header та footer знаходяться в папці `includes/`:
- `includes/header.html` - шапка сайту
- `includes/footer.html` - підвал сайту

### Варіант 1: Автоматичне підключення (рекомендовано для нових сторінок)

Використовуйте файл `template.html` як основу для нових сторінок.

1. Скопіюйте `template.html`
2. Змініть назву файлу (наприклад, `ui-ux-design.html`)
3. Оновіть meta-теги (title, description)
4. Додайте свій контент між header та footer placeholder
5. Header та footer автоматично завантажаться через `js/includes.js`

**Важливо:**
- Додайте `<div id="header-placeholder"></div>` для header
- Додайте `<div id="footer-placeholder"></div>` для footer
- Підключіть `<script src="js/includes.js"></script>` перед main.js

### Варіант 2: Прямий HTML (поточний підхід)

Якщо потрібно працювати без JavaScript або для існуючих сторінок:

1. Скопіюйте header з `includes/header.html`
2. Вставте його прямо в HTML
3. Скопіюйте footer з `includes/footer.html`
4. Вставте його в кінець перед закриттям body

**Оновлення всіх сторінок:**
Якщо змінили header або footer в `includes/`, потрібно оновити їх на всіх сторінках де використовується прямий HTML.

## Структура нової сторінки

```html
<!DOCTYPE html>
<html lang="uk">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Назва — Artyne Studio</title>
  
  <!-- Стилі -->
  <link rel="stylesheet" href="css/style.css">
  <link rel="stylesheet" href="css/landing.css">
  <link rel="stylesheet" href="css/corporate.css">
  <link rel="icon" type="image/png" href="src/favicon.png" />
</head>

<body class="dark-page">

  <!-- Canvas для анімації (геометричні фігури) -->
  <canvas id="lightGrid"></canvas>
  <canvas id="particleCloud"></canvas>

  <!-- Header -->
  <div id="header-placeholder"></div>

  <!-- Контент сторінки -->
  <section class="hero-landing grid-bg">
    <!-- Ваш контент -->
  </section>

  <!-- Footer -->
  <div id="footer-placeholder"></div>

  <!-- JavaScript -->
  <script src="js/includes.js"></script>
  <script src="js/main.js"></script>
  <script src="js/corporate.js"></script>
</body>
</html>
```

## Анімація фону

- **Landing.html** - використовує `js/landing.js` (particles + light grid)
- **Інші сторінки** - використовують `js/corporate.js` (hexagons + triangles)

## Z-index структура

- Canvas: `z-index: 0` (фон)
- Header: `z-index: 100` (щоб submenu працювало)
- Submenu: `z-index: 10`
- Контент: `z-index: 1`

## Важливо!

1. Завжди додавайте `class="dark-page"` до `<body>`
2. Canvas елементи мають бути відразу після відкриття `<body>`
3. Для коректної роботи навігації підключайте `js/main.js`
4. Header має бути перед основним контентом
