# ✅ Чеклист запуску сайту Artyne Studio

## 🚀 Перед запуском на хостинг

### 1. Файли та контент
- [ ] Перевірити всі зображення (чи є alt атрибути)
- [ ] Перевірити всі посилання (чи працюють)
- [ ] Перевірити форми (чи відправляються)
- [ ] Замінити placeholder тексти на реальні
- [ ] Додати реальні номери телефонів
- [ ] Перевірити email адреси

### 2. SEO налаштування
- [ ] Змінити URL у Open Graph тегах на реальний домен
- [ ] Оновити sitemap.xml з реальними URL
- [ ] Перевірити robots.txt
- [ ] Додати favicon всіх розмірів (16x16, 32x32, 180x180)
- [ ] Перевірити Schema.org розмітку на [validator.schema.org](https://validator.schema.org)

### 3. Продуктивність
- [ ] Оптимізувати відео (background.mp4) — стиснути до 2-5 МБ
- [ ] Конвертувати зображення у WebP
- [ ] Мінімізувати CSS (style.css → style.min.css)
- [ ] Мінімізувати JS (main.js → main.min.js)
- [ ] Додати lazy loading для зображень

### 4. Безпека
- [ ] Змінити URL Telegram Bot Worker на власний
- [ ] Налаштувати HTTPS сертифікат
- [ ] Перевірити .htaccess (чи працює на вашому хостингу)
- [ ] Додати Google reCAPTCHA (опціонально)

### 5. Аналітика
- [ ] Додати Google Analytics код
- [ ] Додати Google Tag Manager (опціонально)
- [ ] Додати Facebook Pixel (якщо потрібна реклама)
- [ ] Налаштувати конверсії в GA4

## 🌐 Після запуску

### 1. Google Search Console
- [ ] Додати сайт у [Google Search Console](https://search.google.com/search-console)
- [ ] Завантажити sitemap.xml
- [ ] Запросити індексацію головної сторінки
- [ ] Налаштувати веб-мастерів Bing (опціонально)

### 2. Тестування швидкості
- [ ] Протестувати на [PageSpeed Insights](https://pagespeed.web.dev/)
- [ ] Протестувати на [GTmetrix](https://gtmetrix.com/)
- [ ] Досягти оцінки 90+ на мобільних
- [ ] Виправити всі червоні/жовті попередження

### 3. Тестування доступності
- [ ] Перевірити на [WAVE](https://wave.webaim.org/)
- [ ] Перевірити контрастність тексту
- [ ] Протестувати навігацію лише з клавіатури (Tab, Enter, Esc)
- [ ] Перевірити з screen reader (NVDA/JAWS)

### 4. Кросбраузерне тестування
- [ ] Google Chrome (останні 2 версії)
- [ ] Mozilla Firefox (останні 2 версії)
- [ ] Safari (Mac/iOS)
- [ ] Edge
- [ ] Мобільні браузери (Chrome Mobile, Safari Mobile)

### 5. Адаптивність
- [ ] Desktop (1920x1080, 1366x768)
- [ ] Tablet (768x1024, 1024x768)
- [ ] Mobile (375x667, 390x844, 414x896)

### 6. Соціальні мережі
- [ ] Перевірити Open Graph на [OpenGraph.xyz](https://www.opengraph.xyz/)
- [ ] Перевірити Twitter Card на [Twitter Card Validator](https://cards-dev.twitter.com/validator)
- [ ] Зробити пост з посиланням на сайт (перевірити preview)
