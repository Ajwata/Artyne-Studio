## 🛠 Що потрібно налаштувати

### 1. Cloudflare Worker URL (ОБОВ'ЯЗКОВО!)

У файлі `js/landing.js` (рядок ~70) замініть URL:

```javascript
const response = await fetch('https://YOUR-WORKER.workers.dev/', {
```

**Де взяти URL?**
- Створіть Worker за інструкцією: `telegram-bot/READY_TO_COPY.md`
- Скопіюйте URL після деплою
- Вставте його в код

### 2. Реальні кейси (РЕКОМЕНДОВАНО)

Зараз використовуються іконки-плейсхолдери. Додайте скріншоти:

```html
<!-- Було -->
<div class="case-image" style="background: gradient...">
  <i class="bi bi-heart-pulse"></i>
</div>

<!-- Стане -->
<div class="case-image">
  <img src="src/case-dental-clinic.jpg" alt="Сайт стоматології">
</div>
```

Збережіть скріншоти у папку `src/`:
- `case-dental-clinic.jpg`
- `case-construction.jpg`
- `case-furniture-shop.jpg`

### 3. Google Analytics (РЕКОМЕНДОВАНО)

Додайте код перед `</head>` у Landing.html:

```html
<!-- Google Analytics -->
<script async src="https://www.googletagmanager.com/gtag/js?id=G-XXXXXXXXXX"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
  gtag('config', 'G-XXXXXXXXXX');
</script>
```

**Як отримати код:**
1. Зареєструйтесь на [analytics.google.com](https://analytics.google.com)
2. Створіть властивість для сайту
3. Скопіюйте код відстеження


### Зміна тарифів
У файлі `Landing.html` знайдіть секцію `pricing-section`:


## ❓ Часті питання

### Чи працює форма без Cloudflare Worker?
Ні. Потрібно створити Worker та вставити URL у `js/landing.js`.

### Чи можна змінити дизайн?
Так! Всі стилі в `css/landing.css`. Змінюйте кольори, шрифти, розміри.

### Як додати нову секцію?
Скопіюйте структуру існуючої секції, змініть контент та додайте стилі.

### Чому кейси без фото?
Це плейсхолдери. Додайте реальні скріншоти проектів у папку `src/`.

### Як налаштувати A/B тестування?
Використайте Google Optimize або створіть 2 версії Landing.html.
