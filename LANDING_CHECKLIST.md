
  ```bash

  git push
  ```
- [ ] Перевірив що GitHub Pages працює через 2-3 хвилини

## ⚠️ Типові помилки

### ❌ Форма не працює
**Причина:** Не вказав Worker URL в js/landing.js  
**Рішення:** Перевір рядок ~70, має бути твій Worker URL

### ❌ Сайт не в Google
**Причина:** Не відправив sitemap.xml в Search Console  
**Рішення:** Додай сайт у Search Console → Sitemaps → надішли `sitemap.xml`

### ❌ Низька конверсія (<1%)
**Причина:** Недостатньо соціальних доказів  
**Рішення:** Додай відгуки, логотипи клієнтів, сертифікати

### ❌ Повільне завантаження
**Причина:** Великі зображення  
**Рішення:** Оптимізуй фото через [TinyPNG](https://tinypng.com)
