🔍 Тест Favicon для Artyne Studio

1. Прямая ссылка на favicon

Попробуйте открыть: favicon.ico

Если файл открывается - ✅ favicon существует

2. Визуальная проверка

Favicon должен отображаться в табе браузера ⬆️

3. Проверка путей

  • Относительный путь: favicon.ico
  • Полный URL: https://artyne-studio.online/favicon.ico

4. Инструкции

  1. Откройте эту страницу на вашем сайте
  2. Проверьте, виден ли favicon в табе браузера
  3. Нажмите Ctrl+Shift+R для очистки кэша
  4. Если не работает - проверьте консоль браузера (F12)

5. Возможные проблемы

  • Кэш браузера: Нажмите Ctrl+Shift+R или Ctrl+F5
  • GitHub Pages: Подождите 1-2 минуты после деплоя
  • HTTPS: Убедитесь что используете https://
  • Размер файла: favicon.ico должен быть больше 1KB
